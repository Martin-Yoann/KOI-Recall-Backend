SECURITY · COMPLIANCE · QUALITY

安全合规与质量保障导图数据 · 权限 · 防护 · 合规 · 质量

面向 CPSC 监管场景设计:消费者 PII 加密存储、操作全程审计、可报告性闭环,能力未配置时失败关闭(501)而非静默降级。
数据安全 DATA PROTECTION
  • AES-256-GCM 字段加密 — PII 落库加密(FIELD_ENCRYPTION_KEY)
  • HMAC-SHA256 查询哈希 — 密文等值查询(HASH_PEPPER)
  • scrypt 密码哈希 — 消费者与员工凭据
  • 两级 PII 脱敏 — 列表掩码 + 详情按需授权展示
  • Vercel Private Blob — 索赔证据私有存储,非公开链接
  • 密钥分层 — FIELD_ENCRYPTION_KEY 与 HASH_PEPPER 独立配置于 .env
访问与权限 ACCESS CONTROL
  • Staff Session 认证 — 登录 · 刷新 · 主动下线
  • RBAC 双角色 — ADMIN / MANAGER 权限矩阵前后端镜像
  • staff.manage 仅 ADMIN — 员工与权限管理最小化
  • 后端为权限权威 — 越权 403 + 拒绝动作写入审计
  • 处置细粒度权限 — disposal.review 等独立能力位
  • 案件认领制 — cases/assign 指派处理人,责任到人
可靠性与防滥用 RELIABILITY
  • Upstash 跨实例限流 — 案件查询 10 次/分 · 后台登录 5 次/分
  • Idempotency-Key 幂等 — 重复提交不产生重复案件
  • 单事务写入 + Outbox — 建案与通知最终一致
  • 失败关闭 — 能力未配置返回 501,不静默降级
  • 受保护运维路由 — 缓存失效 / 内部任务需密钥
  • 草稿过期清理 — cleanup-drafts 定时任务回收匿名草稿
通信安全 COMMUNICATION
  • Svix webhook 验签 — Resend 回执防伪造
  • 一次性 upload token — 证据直传绑定草稿 + 回调校验
  • 恶意软件扫描 — 上传证据经 Vercel Blob 安全检测
  • CRON_SECRET — outbox / cleanup 内部任务令牌保护
  • 9 触点事务邮件 — 品牌模板 · 状态变更即时告知
  • 发信域配置 — koiimprtinc.com 自有域名发信
合规与可追溯 COMPLIANCE
  • CPSC 可报告性闭环 — pending → filed(含 CPSC 编号)/ documented_non_reportable
  • 伤害事故强制升级 — escalated 状态 + Case Escalation
  • closure_review 双门闩 — 处置完成 + 可报告性关闭方可 closed
  • 审计事件全留痕 — 关键操作可回溯(audit-events)
  • 架构决策记录 — 5 份 ADR + claim-before-disposal 决策
  • 先建案后处置 — 处置任务必须挂在已建案件之下
质量保障 QUALITY ASSURANCE
  • Vitest 三层测试 — 静态 → 单元/HTTP → PostgreSQL 集成(gated)
  • D01–D29 验收矩阵 — 处置功能 proven / unproven 分级验收
  • CI 门禁全绿 — typecheck · lint · openapi:check · db:check · vitest
  • 三仓库冒烟测试 — 脚本化页面快照与 API 响应留档
  • 契约与结构防漂移 — openapi:check + db:check 双检查
  • 容量基准脚本 — capacity-benchmark(尚未体系化)
⚠ 遗留风险与待办

邮件时效:Vercel Hobby cron 每日仅一次,通知最长延迟 24h(建议升 Pro)· 负载测试缺失:容量基准脚本已有(capacity-benchmark)未成体系 · 遗留桥接:shared-claims-store localStorage 待退出 · D27:处置内容包待业务定稿 · E4:部分业务材料未齐
